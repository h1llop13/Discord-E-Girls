# Discord E-Girls Bot v0.1.2 — полный локальный запуск

Эта инструкция рассчитана на чистый компьютер. Предварительное знание Git, Node.js,
Docker или PostgreSQL не требуется.

## Что понадобится

- Windows 10/11 (64-bit) или актуальная macOS;
- стабильное подключение к интернету для первой установки;
- Discord-аккаунт с правом управлять нужным сервером;
- не менее 5 GB свободного места для Node.js, Docker Desktop, образа PostgreSQL и проекта.

Git устанавливать не нужно: проект можно скачать ZIP-архивом.

## 1. Скачайте и распакуйте проект

1. Откройте [страницу релиза v0.1.2](https://github.com/h1llop13/Discord-E-Girls/releases/tag/v0.1.2).
2. Внизу страницы раскройте **Assets** и нажмите **Source code (zip)**.
3. Дождитесь загрузки и полностью распакуйте ZIP. Не запускайте бота прямо из архива.
4. Поместите распакованную папку в постоянное место, например в `Documents`.

## 2. Установите Node.js

1. Откройте [официальную страницу Node.js](https://nodejs.org/en/download).
2. Выберите актуальную **LTS**-версию 22 или новее и обычный установщик для своей системы.
3. Запустите установщик и оставьте стандартные параметры. npm установится вместе с Node.js.

Для проверки откройте новое окно PowerShell на Windows или Терминал на macOS и выполните:

```text
node --version
npm --version
```

Первая команда должна показать `v22` или более новую версию.

## 3. Установите Docker Desktop

### Windows

1. Откройте [официальную инструкцию Docker Desktop для Windows](https://docs.docker.com/desktop/setup/install/windows-install/).
2. Скачайте версию для свого процессора. Для обычного Intel/AMD-компьютера это **x86_64**.
3. Запустите `Docker Desktop Installer.exe`. Для большинства компьютеров подходит режим **WSL 2**.
4. Если Docker сообщит, что WSL не установлен, откройте PowerShell **от имени администра**, выполните
   `wsl --install`, перезагрузите компьютер и повторите установку.
5. Откройте Docker Desktop, примите его условия и дождитесь статуса **Engine running**.
6. Оставьте режим Linux containers, который включён по умолчанию.

### macOS

1. Откройте [официальную инструкцию Docker Desktop для Mac](https://docs.docker.com/desktop/setup/install/mac-install/).
2. Нажмите **Apple silicon**, если на Mac установлен чип M1/M2/M3/M4/M5, или **Intel chip** для Intel Mac.
3. Откройте скачанный `Docker.dmg`, перетащите Docker в `Applications`, затем запустите Docker.
4. Подтвердите запросы macOS, примите условия Docker и дождитесь запуска движка.

## 4. Создайте и настройте Discord-бота

### 4.1. Discord Developer Portal

1. Откройте [Discord Developer Portal](https://discord.com/developers/applications) в браузере.
2. Нажмите **New Application**, введите имя и создайте приложение.
3. На странице **General Information** скопируйте **Application ID**.
4. Откройте раздел **Bot**. Создайте бота, если Portal ещё не сделал это автоматически.
5. Нажмите **Reset Token**, скопируйте токен и сохраните его в безопасном месте. Это пароль бота.
6. На той же странице включите **Server Members Intent** и **Message Content Intent**, затем сохраните изменения.
7. В **OAuth2 → URL Generator** или в актуальном разделе **Installation** выберите `bot` и `applications.commands`.
8. Выдайте боту права: **View Channels**, **Send Messages**, **Read Message History**, **Manage Messages**,
   **Manage Roles**, **Manage Channels**, **Connect**, **Speak** и **Move Members**.
9. Откройте созданную ссылку, выберите нужный сервер и добавьте бота.

### 4.2. Discord-сервер

1. В Discord откройте **Настройки пользователя → Расширенные** и включите **Режим разработчика**.
2. В настройках сервера создайте роли `👑 Куратор`, `🛒 Клиент` и `💕 E-Girl`.
3. Переместите роль бота выше `🛒 Клиент`. Иначе Discord не позволит боту выдавать и снимать эту роль.
4. Выдайте роль `👑 Куратор` тем, кто будет управлять кодами и заказами.
5. Создайте текстовый канал для приёма кодов, например `#приём-кодов`.
6. Создайте текстовый канал журнала, например `#логи-заказов`.
7. Создайте категорию для приватных голосовых комнат, например `🔒 Приват`.
8. Правой кнопкой нажимайте на сервер, каналы, категорию и роли и выбирайте **Копировать ID**.

Понадобятся ID сервера, двух текстовых каналов, категории и трёх ролей.

## 5. Создайте файл `.env`

Файл `.env` хранит токен бота и ID серва. GitHub намеренно не включает этот файл в релиз.

### Windows

1. В Проводнике откройте распакованную папку проекта.
2. Включите **Вид → Показать → Расширения имён файлов**.
3. Скопируйте `.env.example`, вставьте копию рядом и переименуйте её точно в `.env` без `.txt`.
4. Нажмите по `.env` правой кнопкой и откройте его в Блокноте.

### macOS

1. Откройте Терминал.
2. Напишите `cd ` с пробелом, перетащите папку проекта из Finder в окно Терминала и нажмите Enter.
3. Выполните:

```bash
cp .env.example .env
open -e .env
```

### Заполнение

Замените значения `replace_with_...` в созданном `.env`:

| Переменная | Значение |
| --- | --- |
| `DISCORD_TOKEN` | Секретный токен со страницы Bot |
| `DISCORD_APPLICATION_ID` | Application ID из General Information |
| `DISCORD_GUILD_ID` | ID Discord-сервера |
| `COMMAND_CHANNEL_ID` | ID канала приёма кодов |
| `ORDER_LOG_CHANNEL_ID` | ID канала журнала |
| `PRIVATE_CATEGORY_ID` | ID категории приватных комнат |
| `CURATOR_ROLE_ID` | ID роли куратора |
| `CLIENT_ROLE_ID` | ID роли клиента |
| `EGIRL_ROLE_ID` | ID роли E-Girl |

Строки PostgreSQL для штатного Docker-запуска уже указаны в `.env.example`:

```dotenv
DATABASE_URL=postgresql://discord_bot@127.0.0.1:5433/discord_bot
TEST_DATABASE_URL=postgresql://discord_bot@127.0.0.1:5433/discord_bot_test
```

На время короткой ручной проверки можно указать `TEST_MODE=true`: таймеры станут короткими.
Для обычной работы оставьте `TEST_MODE=false`. Не добавляйте пробелы вокруг `=`.

## 6. Запустите бота одним файлом

### Windows

1. Откройте папку проекта в Проводнике.
2. Дважды нажмите `Запустить бота Windows.cmd`.
3. Если SmartScreen покажет предупреждение, нажмите **Подробнее → Выполнить в любом случае**.

### macOS

1. Откройте папку проекта в Finder.
2. При первом запуске нажмите по `Запустить бота.command` правой кнопкой и выберите **Открыть**.
3. Подтвердите открытие. В следующие разы можно запускать файл обычным двойным нажатием.

Если macOS сообщит, что файл не может быть исполнен, сначала выполните в Терминале из папки проекта:

```bash
chmod +x "Запустить бота.command"
```

Файл запуска сам:

1. найдёт Node.js, npm и Docker;
2. откроет Docker Desktop, если он выключен;
3. запустит PostgreSQL и дождётся его готовности;
4. установит npm-зависимости;
5. применит миграции базы;
6. соберёт и запустит бота.

Первая установка может занять несколько минут. Успешный запуск закончится строкой вида:

```text
Discord bot Name#0000 connected to Server Name.
```

Не закрывайте окно PowerShell/Терминала, пока бот должен работать.

## 7. Первая проверка

1. В Discord откройте настроенный сервер.
2. От пользователя с ролью куратора выполните `/bot-status`.
3. Ожидаемый ответ: `Бот подключён, база доступна, конфигурация сервера загружена`.
4. Создайте первые коды командой `/codes generate quantity:3`.

## 8. Остановка и повторный запуск

- Для остановки нажмите `Control + C` в окне, где работает бот.
- PostgreSQL останется в Docker, а данные и коды сохранятся.
- Для повторного запуска снова откройте тот же `.cmd` или `.command`-файл.
- Бот работает только пока компьютер включён, не спит и окно бота не закрыто.

## 9. Частые ошибки

### `Node.js не найден`

Установите LTS-версию Node.js, закройте все окна PowerShell/Терминала и повторите запуск.

### `Docker не найден` или Docker не запускается

Откройте Docker Desktop вручную. На Windows проверьте WSL команой `wsl --version`; при необходимости
в PowerShell от имени администра выполните `wsl --update` и перезагрузите компьютер.

### Ошибка `.env` или `Invalid environment configuration`

Убедитесь, что файл называется именно `.env`, а не `.env.txt`; все девять Discord-значений заполнены;
ID состоят только из цифр; вокруг `=` нет пробелов.

### Бот подключился, но не видит коды

В Developer Portal включите **Message Content Intent**. Убедитесь, что код отправлен именно в канал с ID из `COMMAND_CHANNEL_ID`.

### Бот не может выдать роль или создать канал

Переместите роль бота выше роли клиента и проверьте права **Manage Roles**, **Manage Channels** и **View Channels**.

### Бот внезапно перестал работать

Не закрывайте окно бота и отключите автопереход компьютера в сон. Локальный запуск не является круглосуточным хостингом.

## Безопасность

- Никогда не публикуйте и не пересылайте `.env`, Discord-токен и CSV с неиспользованными кодами.
- Если токен попал в чат, скриншот, лог или GitHub, немедленно нажмите **Reset Token** в Developer Portal и замените его в `.env`.
- Запускайте только один экземпляр бота.
